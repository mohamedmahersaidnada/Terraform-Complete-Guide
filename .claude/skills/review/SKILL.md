# Independent Review
Review current diff as an independent reviewer. Do not edit. Inspect surrounding code and tests. Rank concrete findings Critical/High/Medium/Low with evidence. Check correctness, regressions, security, concurrency, compatibility, error handling, test gaps, performance and operations. If no material findings, say so and list residual unverified areas.
