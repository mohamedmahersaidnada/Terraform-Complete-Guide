# Project Init
Perform repository onboarding. Do not modify application code. Detect Brownfield vs Greenfield; inventory languages/frameworks/package managers; map directories and architecture; inspect README/docs, git status/history, tests, CI/CD, containers, IaC, deployment, security config and dependency manifests. Run only safe read-only discovery commands. Create or carefully merge `project-memory/*` and missing docs templates. Produce a prioritized baseline with Observed/Inferred/Unverified labels. Do not install packages or run deployments.
