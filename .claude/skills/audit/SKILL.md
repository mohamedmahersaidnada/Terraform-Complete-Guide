# Full Audit
Audit the repository without changing implementation. Cover correctness, architecture, maintainability, security, dependencies, tests, CI/CD, infra, data, observability, performance, documentation and operational readiness. Use specialists when relevant. Findings must include severity, evidence/location, impact, remediation and verification method. Deduplicate findings. Update KNOWN_GAPS/RISK_REGISTER only after evidence is established.
